# 08 — Recovery table: the standing-ruling export, cleanups and orphans

A bounded specification of what each command does in each state of one lifecycle: the
standing-ruling export (`resolve --standing` → `export-rulings` → the owner's commit), the
cleanup obligations and orphan intents beside it, the remembered tree (`expect`) and the branch
tip. It covers only the states the recovery journeys RUN-82 to RUN-90 and PROC-32 reach and their
neighbours; it is not a specification of the runner. Each cell is derived from the code
(`cli.cmd_export_rulings`/`_only_restored`, `engine._adopt_tip`/`retry`/`finish_run`/`remember_tree`,
`findings.missing_exports`,
`record.reconcile`/`_export_committed`, `replan.prepare`, `status.export_next_steps`/
`_resume_lines`, `cli._open_run`) and names the scenario whose test pins it, or **gap** when no
test drives that command in that state. Nothing is generated from this table.

## The dimensions

| Dimension | Values |
|---|---|
| export | **queued** (`standing_pending` entry not `written`) · **exported** (written, file uncommitted) · **committed** (the owner's commit of exactly the exported files) · **missing** (written, and no longer in its file in the work tree: put back or removed instead of committed) · **refused** (the export refused or failed; the state is as before) |
| cleanup | **open** (an obligation whose group stop failed) · **abandoned/closed** |
| orphan intent | **alive** (a call's group from a dead runner still runs) · **stopped** |
| remembered tree (`expect`) | **set** (`{tip, tree}`) · **None** (a stop that asked for a change, a failed write at `done`, or a snapshot that failed: an unregistered embedded repository; a checked-out registered submodule no longer fails it since C14) |
| tip | **unchanged** · **moved by the export commit** · **moved otherwise** |
